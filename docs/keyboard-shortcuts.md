## Navigation keys

| Shortcut                                                           | Action                                         |
| ------------------------------------------------------------------ | ---------------------------------------------- |
| F6 / Shift+F6                                                      | Move to the next / previous pane               |
| Ctrl+Tab / Ctrl+Shift+Tab                                          | Switch open tabs                               |
| In the vault tree: Up/Down, Left/Right, Home/End                   | Move, expand, and collapse                     |
| In the vault tree: Enter, F2, Delete, `*`, first-letter type-ahead | Open, rename, delete, expand siblings, or find |
