# A11y Notebook v1.9.15 — What's new and what changed

Everything in this release was merged since v1.9.14 (November 9, 2026).
It carries the five fixes from the 1.9.14 retest — the spreadsheet
duplicate-worksheet error, the New Task date picker, bookmark jumps,
the AM/PM comboboxes, and search reminder formatting — plus the
notebook silo fix, the ePub reader fix, task announcements, and the
new automated end-to-end test gate that now runs in CI and on every
release.

## What's new

### Notes now appear under only one notebook

- A note created in a new notebook used to show under two notebooks
  at once: the New Notebook dialog had no location choice, so the
  notebook was silently created inside whichever notebook was
  selected, and Notes and Files matched notebooks recursively, so a
  note showed under both the parent and the notebook itself.
- The New Notebook dialog now offers a Location choice — Library root
  (the default) or inside the selected notebook — and after creating
  a notebook the app announces where it was created ("Notebook
  created in the Library root." / "Notebook created inside
  Archive."). Notes and Files now shows a notebook's own notes and
  files plus the notebooks inside it; a sub-notebook's notes only
  appear when that sub-notebook is opened. A note is never listed
  under two notebooks at once.
- If a notebook is already nested in the wrong place, move it to the
  Library root with Organize Library (Alt+Shift+Up).

### ePub books now open in the app again

- Opening an ePub crashed the reader: it called an epubjs API that
  does not exist in epubjs 0.4.2. The reader now opens the book with
  the library's real API. This was a separate bug from the 1.9.14
  fetch fix — ePub and PDF files now open through the fixed reader
  path.

### Automated end-to-end tests now run in CI and on every release

- Playwright end-to-end tests (15 tests, 10 new scenarios) now run as
  a blocking check in CI and as part of the release workflow, so the
  app is exercised the way a user drives it — opening notebooks,
  creating notes and tasks, jumping to bookmarks, importing files —
  before any release ships. The scenarios cover the repeat
  verification items: spreadsheet and CSV import, the notebook silo,
  task auto-link, Ctrl+E focus, bookmark jumps, and ePub/PDF opening.
- Automated tests cannot check screen-reader announcements or the
  virtual-cursor position — manual screen-reader testing remains the
  only check for those.

### Appointment times now have AM/PM comboboxes

- The New appointment dialog's start and end times now have
  accessible AM/PM comboboxes, so the time of day can be set with the
  keyboard without typing it.

### The New Task dialog's date picker buttons are back

- The date picker buttons in the New Task dialog had disappeared; they
  are restored, with the same accessible labels as the other dialogs'
  date pickers.

## What changed (verification fixes)

- **A spreadsheet whose workbook lists the same worksheet twice now
  imports.** The reader compared resolved file paths, not sheet
  names, and non-worksheet sheets (chart, dialog, or macro sheets)
  fell back to a guessed path that collided with a real worksheet.
  Non-worksheet sheets are now skipped. The same fix applies when
  saving a spreadsheet back.
- **Search results show reminder times as MM/DD/YYYY, HH:MM AM/PM.**
  A file result could show a raw task line such as
  `remind:2026-11-08 22:03 - []`. Task lines are now cleaned before
  they reach the snippet, and reminder markers no longer leak into
  the search text.
- **Bookmark jumps now move the virtual cursor the same way Find
  does, and you can bookmark from the reading position.** Jumping to
  a bookmark places a real selection on the target, exactly as Find
  does, and re-selects it after focus lands — both must be true at
  once. Ctrl+Alt+H sets a bookmark on the heading at the reading
  position, and Ctrl+Alt+J bookmarks the cursor position; neither
  jumps.
- **Repeated task lines are now announced every time.** Creating
  several tasks in a row in a note used to announce only the first
  "task": the announcement went to a live region that only speaks
  when its text changes, and every line set the identical string.
  The announcement now clears and re-sets each time, so the screen
  reader says "task" after each Enter. The same fix covers repeated
  "bullet" and "List ended." announcements.
- **Long notebook names no longer shift the grid.** At a narrow
  window the header wrapped onto a second line when a long notebook
  name was selected, pushing the grid down by more than a row between
  the two clicks of a double-click — the second click landed on the
  row above and the notebook never opened. Long scope and
  current-item names are now capped with an ellipsis, so the header
  can never wrap; the full name is still the item's accessible name.

## Known limitations

- The Citations dialog's "Switch to edit mode" button deliberately
  does not move focus while the dialog is open: focus must stay in
  the dialog so a citation can be inserted.
- F3 and Shift+F3 remain intercepted by JAWS in browse mode; use the
  Find match list, or Insert+3 (JAWS pass-through) then F3, to repeat
  a search.
- Mac releases ship unsigned (right-click, then Open, to install; no
  Mac auto-update while unsigned).
- PDF, ePub, and DOCX previews keep their own search boxes; the Find
  match list does not cover them.
- Very large spreadsheets (thousands of rows) may be slow to display;
  the reader caps workbooks at 10,000 rows, 256 columns, and 500,000
  cells, and slide decks at 500 slides. Spreadsheet save preserves the
  file's styles, images, and other parts; ODS cells keep their original
  cell styles. `.xls` reading uses the SheetJS community edition
  (Apache-2.0) — the one format without an in-house reader.
- A permanent delete of a note containing tasks still shows the app's
  existing native permanent-delete confirmation after the task guard.
- The automated end-to-end tests cannot check screen-reader
  announcements or the virtual-cursor position; manual screen-reader
  testing remains the only check for those.
- Items still awaiting a retest verdict: move-migration link survival,
  import formats, ePub chapter resume, PDF navigation and annotation
  persistence, audio features (real microphone, model download,
  dictation accuracy, playback with a screen reader, mp3/wav import),
  and the library picker.

## Mac install note

Mac builds are not signed yet. To install, right-click (or Control-click) the .dmg file, then choose Open. In-app updates do not work on Mac while the builds are unsigned — install each new version manually from the releases page.
