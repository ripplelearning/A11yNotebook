# A11y Notebook v1.9.13 — What's new and what changed

Everything in this release was merged since v1.9.12 (November 6, 2026).
It carries the 1.9.12 verification fixes from batch 3: the Quick Task
redesign, global search covering tasks, reminders, and appointments,
the spreadsheet and slide preview fix, the delete guard, bookmark
jump fixes, the appointment delete dialog, and the Citation dialog
toggle removal.

## What's new

### Quick Task redesigned

- The notebook chooser now lives inside the Quick Task dialog, after
  the text box: type the task first, then pick a notebook. The text box
  gets focus first, so a task can be jotted down fast before it is
  forgotten.
- Saving without choosing a notebook (for example, pressing Enter after
  typing) saves the task in the most recent notebook.
- Every Quick Task now confirms with "Task created in [Notebook Name]",
  announced to screen readers and shown on screen — whether or not a
  notebook was already open.
- If no notebook exists at all, a destination must be picked before
  saving. This replaces the earlier prompt-first flow from v1.9.12.

### Global search now covers tasks, reminders, and appointments

- Search results now include tasks, reminders, and calendar
  appointments, not just notes and files. The kind filter gains Task,
  Reminder, and Appointment.
- Results show the type and enough context to tell them apart (task
  text, reminder text and time, appointment title and time).
- Opening a result goes where it belongs: a task opens in the Tasks
  view with the task focused; a reminder opens the Reminders tab with
  the reminder focused; an appointment opens the appointment itself.
- Two honest filter limits: tag and modified-date filters do not apply
  to tasks, reminders, or appointments (they have no tags or modified
  date), so those results are excluded when such a filter is set; the
  notebook filter excludes appointments (they have no notebook).

### Spreadsheets and slide decks open in the app

- Imported `.xlsx`, `.ods`, `.xls`, `.pptx`, and `.odp` files now open
  in the in-app preview (editable grid for spreadsheets, read-only
  text for decks) instead of falling through to "This attachment has
  no in-app preview yet" and opening an external app. The preview
  itself was already built in v1.9.12; the opener was not sending these
  files to it.

## What changed (verification fixes)

- **Deleting a note that contains tasks now warns first.** Deleting a
  note used to delete its tasks silently, because a task is a checklist
  line inside its note and the Tasks view only shows those lines. A
  confirmation now names the task count before anything is deleted,
  for both Delete (trash) and Shift+Delete (permanent). The same guard
  applies when deleting a notebook containing tasks in any note inside
  it. Note: a permanent delete still shows the app's existing native
  permanent-delete confirmation after the guard.
- **Bookmark jumps land, stay, and announce.** Jumping to a bookmark
  from the Bookmarks pane could leave focus at the top of the note, so
  a screen reader's virtual cursor never moved. A jump now verifies
  focus really landed on the target and retries briefly if the view is
  still settling; the landing is announced ("Jumped to \<heading\>.").
  Headings with bold, italic, or link formatting now match their
  bookmarks, and jumps work in rich-text editing too (previously the
  jump did nothing there, because there is no plain text box to focus).
  Ctrl+Alt+H and Ctrl+Alt+J are unchanged: both only set a bookmark,
  neither jumps.
- **Deleting an appointment is now a separate dialog.** The warning
  used to appear inside the edit-appointment dialog without taking
  focus, and the Delete button that had focus vanished, dropping focus
  to the top. Deleting now opens its own dialog with just the message
  and the choices, and focus moves into it. Single appointments say
  "Delete this appointment?" instead of talking about a whole series;
  recurring appointments keep the "Deleting removes the whole series,
  not just one occurrence." warning.
- **The Bibliography toggle is gone from the Citations dialog.** The
  toggle switched views but moved no focus and announced nothing, so
  it read as broken. Views now switch only with the keyboard: Ctrl+J
  opens the Bibliography, Ctrl+Shift+C opens the Citation generator.
- **Import failures now name the real reason.** A failed import used
  to collapse every cause into "Could not import the selected file."
  The message now carries the underlying reason (for example, what the
  spreadsheet reader rejected). The `.gdoc` guidance message is
  unchanged.
- **Google link files (.gdoc, .gsheet, .gslides) say why the link
  could not be read.** When the address inside the file cannot be
  read, the app now reports the specific problem (empty file, not
  valid JSON, no address, or unreadable) instead of silently showing
  only the download guidance. A leading invisible character at the
  start of the file no longer breaks the read.
- **Bibliography hanging indent verified.** The indent (0.5 in) is
  applied for APA, MLA, and both Chicago styles, but only in the
  inserted bibliography block in an HTML note. Markdown and plain-text
  notes cannot carry indentation, spacing, or font, so a bibliography
  in a Markdown note shows no hanging indent — that is a limit of
  Markdown, not a bug. No code changed for this item.

## Known limitations

- F3 and Shift+F3 remain intercepted by JAWS in browse mode; use the
  Find match list, or Insert+3 (JAWS pass-through) then F3, to repeat
  a search.
- Mac releases ship unsigned (right-click, then Open, to install; no
  Mac auto-update while unsigned).
- PDF, ePub, and DOCX previews keep their own search boxes; the Find
  match list does not cover them.
- Very large spreadsheets (thousands of rows) may be slow to display;
  the reader caps workbooks at 10,000 rows, 256 columns, and 500,000
  cells, and slide decks at 500 slides. Spreadsheet save preserves the
  file's styles, images, and other parts; ODS cells keep their original
  cell styles. `.xls` reading uses the SheetJS community edition
  (Apache-2.0) — the one format without an in-house reader.
- Items still awaiting a retest verdict: move-migration link survival,
  import formats, ePub chapter resume, PDF navigation and annotation
  persistence.

## Mac install note

Mac builds are not signed yet. To install, right-click (or Control-click) the .dmg file, then choose Open. In-app updates do not work on Mac while the builds are unsigned — install each new version manually from the releases page.
