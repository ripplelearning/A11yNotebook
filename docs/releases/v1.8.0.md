# A11y Notebook v1.8.0 — What's new and what changed

Everything in this release was merged since v1.7.0 (October 25, 2026).

## What's new

- **Focus Mode (F11).** Press F11 with a note or file open, in reading or
  editing mode, and only the titlebar (with global search), the menu bar,
  and the document stay visible and focusable. Everything else hides until
  you press F11 again, close the note, switch views, or restart the app.
  Also available from the View menu and the command palette.
- **High contrast theme.** The Theme setting now offers Dark, Light, and
  High contrast, and all three work in ordinary mode. High contrast is a
  black-and-white palette with yellow links, focus outlines, primary
  buttons, and selected elements. In Windows forced-colors mode the system
  colors still govern.
- **Light theme (WCAG 2.2 AA).** A full light palette with all key pairs
  passing contrast checks (body text 17.85:1). The Theme option previously
  did nothing in ordinary mode; it now works.
- **Calendar with live sync.** A local calendar (agenda list plus month
  grid, single and recurring appointments, links to notes, files, or
  tasks) with two-way sync to Google Calendar, Outlook, and Apple Calendar
  (Apple via CalDAV with an app-specific password). Includes appointment
  reminders, a single "Keep calendar offline" option, and conflict
  resolution that never silently overwrites either side. Press Ctrl+6 to
  open Calendar.
- **Appearance settings and automatic backups.** Theme, zoom, focus
  indicator, and reduced-motion settings, plus scheduled whole-library
  backups with a retention count you choose.
- **Citations.** APA 7, MLA 9, and Chicago 17 citations with a bibliography
  generator (Ctrl+Shift+J).
- **MathML.** Insert math as a durable code span (Alt+=) that renders as
  MathML.
- **Tools: spelling and thesaurus.** Spell check with a custom dictionary
  (F7) and a synonyms-only thesaurus (Shift+F7).
- **Shortcut cleanup.** Every command has a unique, editable keyboard
  shortcut, with automatic detection and rejection of duplicates.
- **Task linking.** From a task's context menu, link to a note, a file, or
  a Notebook; links show in a Links column in the Tasks table.

## What changed

- **Milestones removed entirely.** The feature is gone, including its
  files and commands. Calendar moved to Ctrl+6; Ctrl+7 is deliberately
  left unassigned.
- **Help menu:** Check for Updates is now on the U mnemonic (Alt+H then U).
  The Ctrl+Shift+U shortcut is unchanged.
- **Accessibility audit coverage widened.** The automated audit now runs
  the full WCAG 2.2 tag set. An earlier audit run had called itself
  WCAG 2.1 AA while only running the 2.0 rules; the four 2.1-specific
  rules are now covered and passing.
- **Test reliability.** Suite-wide test timeout raised to 30 seconds for
  slow shared runners, and end-to-end tests now use fresh profiles so one
  test's saved settings cannot leak into another.

## Fixes in this release

- Light and High contrast themes were dead controls in ordinary mode
  (their rules were trapped inside a forced-colors block). Both now work.
- Pressing F11 no longer breaks saving settings (F11 was both a reserved
  key and the new Focus Mode shortcut; it is now exclusive to Focus Mode).
- A duplicated status region that broke several tests is fixed: Focus
  Mode announcements use a temporary live region that clears after
  three seconds.
- A timezone-dependent calendar test that failed on UTC runners now
  asserts instants instead of offset spellings.

## Known limitations

- **Unsigned build.** Windows may show SmartScreen warnings; there is no
  code-signing certificate yet.
- **Calendar sync is not yet tested against real accounts.** Google,
  Outlook, and Apple sync are built and unit-tested, but live-provider
  testing still needs real accounts on Windows.
- **Apple sync uses the first calendar only** (no calendar picker yet),
  and relative recurrence patterns are skipped on pull.
- **First sync can duplicate events** that already exist both locally and
  remotely without a link. Links and reminder choices are local-only and
  do not transfer through a provider to a fresh library.
- **Manual validation still owed on a real Windows machine:**
  JAWS/NVDA/Narrator runs, forced-colors rendering, UI Automation smoke
  runs, Task Scheduler reminder delivery, the paste clipboard path, and
  the reported File Explorer invisibility.
