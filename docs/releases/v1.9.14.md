# A11y Notebook v1.9.14 — What's new and what changed

Everything in this release was merged since v1.9.13 (November 7, 2026).
It carries the 1.9.13 verification fixes from batch 4: the ePub/PDF
reader fix, the spreadsheet and CSV fixes, the Google link fallback,
real file types in the Type column, search reminder formatting,
bookmark jumps that follow the virtual cursor, bookmark naming, task
auto-linking, first-letter navigation, Create Reminder from the grid,
and edit-mode focus on Ctrl+E.

## What's new

### Every .csv file now opens as a spreadsheet

- A `.csv` file used to open the Cognitive Tools view, because the
  asset registry claimed `.csv` files and the opener checked it first.
  Every `.csv` now opens in the spreadsheet grid, like `.xlsx` and
  `.ods`. Grid assets saved as `.csv` still open in the Grid editor
  from the Assets tab.

### Tasks are now automatically linked to the note they were created in

- When a task is created in a note, the Tasks view Links column now
  shows the containing note, with the same actions as any other
  linked item. The link is a real stored link, so it can be removed
  like other links — and a removal is remembered, so the link does
  not come back on the next refresh. This covers tasks created in the
  dialog, with Quick Task, and tasks typed by hand.

### Create Reminder from the Notes & Files grid

- The context menu for a note or a file now offers Create Reminder.
  The new reminder dialog opens with the selected note or file
  already linked to the reminder. The reminder dialog's Link picker
  only shows the File option when files exist in the library.

### First-letter navigation in the grids

- Pressing a letter or number key in the Notes & Files grid now moves
  focus to the next item starting with that character; pressing the
  same key again cycles to the next match, wrapping around. Modified
  keys (Ctrl, Alt, and so on) are ignored.

## What changed (verification fixes)

- **ePub and PDF files should now open in the app.** The v1.9.12 fix
  only did half the job: it enabled fetch support for the app's file
  scheme but left out the cross-origin permission, so the reader's
  fetch still failed with "Failed to fetch" — exactly the same
  symptom as before the fix. This release adds that missing
  permission (one line). The reader path has likely never worked in a
  shipped build, so please retest ePub and PDF and tell me if they
  still fail.
- **A spreadsheet whose workbook lists the same worksheet twice now
  imports.** The reader compared resolved file paths, not sheet
  names, and non-worksheet sheets (chart, dialog, or macro sheets)
  fell back to a guessed path that collided with a real worksheet.
  Non-worksheet sheets are now skipped. The same fix applies when
  saving a spreadsheet back.
- **When a Google link file cannot be read, you can still add it as a
  link.** Importing a `.gdoc`, `.gsheet`, or `.gslides` file whose
  contents cannot be read used to show only the guidance text, with
  no way to add the link. The Add Link dialog now opens anyway, so
  the address can be pasted in and the link added to the notebook.
- **The Type column now shows the real file type.** ePub, PDF,
  `.docx`, and `.doc` files used to read "Attachment" in the Type
  column. They now show their actual type (ePub, PDF, Word document,
  and so on). The Type column still sorts the same way.
- **Search results no longer show raw reminder text.** A file result
  could show a raw task line such as `remind:2026-11-08 22:03 - []`.
  Task lines are now cleaned before they reach the snippet, and
  reminder times in search results read MM/DD/YYYY, HH:MM AM/PM.
- **Bookmark jumps now move the virtual cursor the same way Find
  does.** Jumping to a bookmark used to place only focus on the
  heading, which does not reliably move a screen reader's virtual
  cursor. A jump now places a real selection on the target, exactly
  as Find does, and re-selects it after focus lands — both must be
  true at once. If a jump still cannot land, the app now says so
  instead of failing silently. Ctrl+Alt+H and Ctrl+Alt+J are
  unchanged: both only set a bookmark, neither jumps.
- **Bookmarks can now be named.** When a bookmark is set, a name
  prompt appears with the field pre-filled from the heading or the
  surrounding text; the name can be accepted as-is or edited. Bookmark
  names cannot be edited after creation yet — a Rename action is
  planned for a later release.
- **Switching to edit mode with Ctrl+E now moves focus into the note
  text box automatically.** The caret is restored first, then focus
  lands in the editor, whether the note is in plain-text or rich-text
  editing. Opening a note or switching tabs does not steal focus —
  only the Ctrl+E toggle raises the focus request.

## Known limitations

- The Citations dialog's "Switch to edit mode" button deliberately
  does not move focus while the dialog is open: focus must stay in
  the dialog so a citation can be inserted.
- F3 and Shift+F3 remain intercepted by JAWS in browse mode; use the
  Find match list, or Insert+3 (JAWS pass-through) then F3, to repeat
  a search.
- Mac releases ship unsigned (right-click, then Open, to install; no
  Mac auto-update while unsigned).
- PDF, ePub, and DOCX previews keep their own search boxes; the Find
  match list does not cover them.
- Very large spreadsheets (thousands of rows) may be slow to display;
  the reader caps workbooks at 10,000 rows, 256 columns, and 500,000
  cells, and slide decks at 500 slides. Spreadsheet save preserves the
  file's styles, images, and other parts; ODS cells keep their original
  cell styles. `.xls` reading uses the SheetJS community edition
  (Apache-2.0) — the one format without an in-house reader.
- A permanent delete of a note containing tasks still shows the app's
  existing native permanent-delete confirmation after the task guard.
- Items still awaiting a retest verdict: move-migration link survival,
  import formats, ePub chapter resume, PDF navigation and annotation
  persistence, audio features (real microphone, model download,
  dictation accuracy, playback with a screen reader, mp3/wav import),
  and the library picker.

## Mac install note

Mac builds are not signed yet. To install, right-click (or Control-click) the .dmg file, then choose Open. In-app updates do not work on Mac while the builds are unsigned — install each new version manually from the releases page.
