# A11y Notebook v1.9.11 — What's new and what changed

Everything in this release was merged since v1.9.10 (November 4, 2026).
It carries Quick Task, the 1.9.10 verification fixes, the Find match list,
and the audio features (dictation, audio notes, local Whisper transcription).

## What's new

- **Quick Task (Ctrl+Q).** A small dialog with only a Quick Task text box,
  OK (first and default; Enter in the text box activates OK), and Cancel.
  OK creates a new task in the Tasks list from the text. Quick tasks go to
  the currently open library/notebook; if none is open, pick a library
  first, then pick a notebook from it. On macOS the shortcut is left
  unassigned so the user can assign it themselves.
- **Find match list.** Searching with Ctrl+F now lists every match with
  the text around it, below the search controls. Arrow keys move through
  the list, and Enter on a match closes the dialog and moves to that
  match in the note. This is the workaround for F3 being intercepted by
  JAWS in browse mode: F3 and Shift+F3 themselves are unchanged for
  quick stepping, but the list does not depend on them.
- **Reading-view task checkboxes now toggle.** In reading view, task
  checkboxes are real, enabled checkboxes: activating one completes (or
  reopens) the task in Tasks view, instead of display-only as in 1.9.10.
- **Dictation (Ctrl+Alt+D).** With an editable note open in edit mode,
  start dictation from the Edit menu, the Dictate button, or Ctrl+Alt+D;
  the same shortcut stops it. The recorded segment is transcribed on
  your machine and inserted at the caret. Dictation works in segments,
  not word-by-word as you speak.
- **Audio notes.** File menu, then Record audio note, records into the
  current notebook (or the library root) and opens the saved audio in
  the attachment preview. Audio files (.webm, .mp3, .wav, .m4a, .ogg,
  .flac, up to 40 MB) can also be imported and now open in the app with
  playback controls instead of falling through to the external app.
- **Transcription.** Open an audio file and press Transcribe. The first
  transcription asks which free local Whisper model to download: Smaller
  (Whisper Base, about 150 MB) or Larger (Whisper Small, about 500 MB);
  change it later in Settings under Transcription model. The transcript
  is saved as a note next to the audio (for example, "Interview
  transcript.md"), linked back to the audio file; transcribing again
  replaces it.

## What changed (verification fixes)

- **Settings dialog title.** Opening Settings now names the dialog in the
  window title, so JAWS Insert+T reads "Settings" instead of the view
  behind it; closing Settings restores the view title.
- **Reminder pickers.** Task due and reminder dates and times are now
  plain-text fields you can type in directly, with an AM/PM choice and
  an optional in-dialog calendar — no native date/time picker popup,
  and no tab-loop trap. The last native date inputs in the app
  (citation "Date accessed", search date filters) are now plain
  YYYY-MM-DD text fields.
- **Ctrl+Tab no longer returns to a cancelled appointment.** Closing the
  Calendar tab with Ctrl+W now really closes it, and a cancelled New
  Appointment dialog no longer reopens when returning to the calendar.
- **In-text citations.** The Citation Generator and bibliography entry
  buttons are now "Insert In-Text Citation", and bibliography entries
  have a context menu (right-click, ContextMenu key, or Shift+F10) with
  an "Insert In-Text Citation" option. Inserting still requires edit
  mode; it stays disabled in reading view by design.
- **Google Docs (.gdoc) import guidance.** Importing a .gdoc file now
  shows the explanatory message (a .gdoc file is only a link; export
  from Google Docs and import the downloaded file) instead of a
  generic "Could not import" message. Other import failures still show
  the generic message.
- **Bookmark wording.** The user guide now says plainly that Ctrl+Alt+H
  and Ctrl+Alt+J both only save a bookmark and neither jumps; jump by
  activating the bookmark in the Bookmarks section of the right pane.
- **Notes & Files titlebar, Bibliography heading, library-open focus.**
  The Notes & Files view is titled "Notes & Files" (not "Files"), the
  Citation dialog titles itself "Bibliography" in bibliography view,
  and opening a library puts focus in the Notebooks grid's first column
  header. A library-open focus race is also fixed: the focus step now
  waits out the "Opening library" dialog instead of being trapped by
  it and dropped to the body.
- **Organize Library move announcements.** Alt+Up/Down and
  Alt+Shift+Up/Down moves, and cut-paste moves, now announce the
  destination notebook in the dialog status line ("Library root" for
  the top level).
- **Focus Mode Annotate button.** The Annotate selection button is now
  hidden in all Focus Mode (it was previously visible in plain Focus
  Mode and hidden only with Immersive Focus on). The menu-bar Annotate
  item is intentionally kept.

## Known limitations (unchanged)

- F3 and Shift+F3 remain intercepted by JAWS in browse mode; use the
  Find match list, or Insert+3 (JAWS pass-through) then F3, to repeat
  a search.
- Mac releases ship unsigned (right-click, then Open, to install; no
  Mac auto-update while unsigned).
- PDF, ePub, and DOCX previews keep their own search boxes; the Find
  match list does not cover them.
- Items still awaiting a retest verdict: move-migration link survival,
  import formats, ePub chapter resume, note reading-position resume,
  PDF navigation and annotation persistence.

## Mac install note

Mac builds are not signed yet. To install, right-click (or Control-click) the .dmg file, then choose Open. In-app updates do not work on Mac while the builds are unsigned — install each new version manually from the releases page.
