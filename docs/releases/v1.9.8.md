# A11y Notebook v1.9.8 — What's new and what changed

Everything in this release was merged since v1.9.7 (October 29, 2026).
It carries Tristen's testing batch 4.

## What's new

- **One Export note command.** The two export commands are unified
  into a single **Export note…** (Ctrl+Shift+X). From a note or tab
  menu it exports that note; otherwise it exports the current note.
  The output choices are unchanged: standalone HTML or Markdown.
- **Markdown lists continue themselves.** In Markdown source, pressing
  **Enter** on a list item inserts the next item: numbered lists
  increment, and checked task items continue as fresh unchecked items.
  Pressing **Enter** on an empty list item ends the list, so pressing
  Enter twice in a row stops the list, like Word and Google Docs.
- **Closed libraries stay closed.** Closing a library now forgets it,
  so it is no longer restored on the next launch. A library that is
  restored (because it was still open) lands on the Notebooks view.

## What changed

- **Older notes open without the external-file dialog.** Notes and
  files created or imported before provenance records existed no
  longer prompt with the external-file dialog on open, reopen, or
  tree-view open; they open natively like any other library item.
  Unsupported file types still prompt, and the legacy-encrypted
  recovery path is unchanged.
- **Reminder and task dates and times are plain text fields.**
  Reminder dialogs and task dialogs now use text fields labelled with
  their format (YYYY-MM-DD and HH:MM) instead of native date and time
  pickers, which JAWS misread with a spoken language tag and which
  trapped focus in a tab loop. Invalid dates and times are rejected
  with a message naming the expected format.
- **Search scope stays after the search box with no library open.**
  The scope controls are now always rendered right after the search
  box; with no library open they are shown disabled instead of being
  absent.
- **Open tabs sit outside the main landmark.** The main landmark now
  contains only the current tab's content, so the tabs themselves are
  no longer listed inside it.

## Known limitations

- Mac releases ship unsigned: install with right-click, then Open.
  Mac auto-update does not work while releases are unsigned.
