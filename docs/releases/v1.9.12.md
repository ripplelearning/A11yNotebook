# A11y Notebook v1.9.12 — What's new and what changed

Everything in this release was merged since v1.9.11 (November 5, 2026).
It carries spreadsheets and slide decks, bibliography formatting with
Chicago notes-bibliography, the math mixed-fraction fix, link notes, and
the 1.9.11 verification fixes from batches 1 and 2.

## What's new

### Spreadsheets: import, read, and edit

- Import `.xlsx`, `.ods`, `.csv`, and old binary `.xls` files (up to 40 MB)
  into any library, like any attachment.
- Open a spreadsheet in an editable grid: row numbers and column letters,
  every cell a labelled text box. Numbers stay numbers, TRUE/FALSE stay
  true and false, dates stay dates, and formula cells show their calculated
  value (editing one replaces the formula with the typed value).
- Add rows and columns at the end of a sheet; delete the row or column the
  focused cell is in. Workbooks with more than one sheet get a sheet picker.
- Save with Ctrl+S (or the Save button) back into the same file, like a
  note. `.xls` files save as a new `.xlsx` file next to the original; the
  original is left unchanged.
- Formulas show cached values only — there is no formula engine, and
  editing stores the typed value.

### Slide decks: import and read

- Import `.pptx` and `.odp` files (up to 40 MB). Decks open as read-only
  text: a list of slides with titles, body text, and speaker notes.
- Slide editing comes in a later release.

### Formats that need an export first

- Apple Numbers (`.numbers`), Apple Keynote (`.key`), and old PowerPoint
  (`.ppt`) files cannot be read directly. The app explains how to export
  them as `.xlsx` or `.pptx` and import that file.
- Google Sheets (`.gsheet`) and Google Slides (`.gslides`) files are only
  links: the app explains how to download them as `.xlsx`, `.csv`, or
  `.pptx` and import that file.

### Bibliography formatting and Chicago notes-bibliography

- Bibliographies now format correctly for APA 7th, MLA 9th, and Chicago
  17th: each style gets its heading (References, Works Cited, or
  Bibliography), hanging indentation, correct line spacing, and Times New
  Roman 12 pt, in HTML notes.
- A new "Chicago (Notes-Bibliography)" style joins "Chicago
  (Author-Date)": footnotes in the note, numbered from 1, with a Notes
  section at the end, and a bibliography with the year at the end of each
  entry.
- Several citation text fixes: "(Ed.)" for a single editor in APA,
  retrieval dates only for undated web pages, APA in-text page numbers,
  same-author sorting, MLA URLs without the "https://" prefix, and Chicago
  conference place and date.
- Honest limits are shown in the dialog and user guide: Markdown and
  plain-text notes cannot carry hanging indent, spacing, or font; APA
  sentence case for titles is the writer's responsibility.

### Link notes

- Add a web link to a notebook as a grid item with Type "Link"
  (File menu, Add link button, or Ctrl+Alt+L). Links open in the default
  web browser, and their title and address can be edited afterwards.
- Importing a `.gdoc`, `.gsheet`, or `.gslides` file now offers a choice:
  add it as a link, or follow the download-and-import guidance as before.
  Link titles are searchable.

## What changed (verification fixes)

- **ePub and PDF "Failed to fetch" fixed.** Opening an imported ePub or
  PDF could fail with "Failed to fetch" because the app's file scheme did
  not allow fetch requests. The reader can now load the file's bytes.
- **Task reminders now fire.** A reminder added to a task in a note
  (for example, one minute later) could be missed entirely: the reminder
  service only learned about it when the file watcher happened to notice
  the save. Saving a note now refreshes reminders directly. The save
  path also keeps schedule markers before the task's id marker, so a
  reminder keeps its identity when the note text above it changes.
- **Note metadata shortcut is now Ctrl+M** (was Ctrl+Shift+D).
- **Tasks Due date reads MM-DD-YYYY**, and "MM-DD-YYYY at H:MM AM/PM"
  when a time is set.
- **Deleting a note removes its link from tasks.** A task linking to a
  deleted note no longer keeps a dead link; opening a dead link removes
  it with an explanation, and refreshing the view prunes dead links.
- **Bookmark jump holds its landing.** Jumping to a bookmark from the
  Bookmarks pane could look like nothing happened when switching between
  edit and reading view, because the reading-position resume pulled focus
  back to the saved heading. A jump now re-lands on the bookmarked
  heading; reopening the note later still resumes where you left off
  reading. Ctrl+Alt+H and Ctrl+Alt+J are unchanged: both only set a
  bookmark, neither jumps.
- **Math: mixed fractions.** Typing `3/4+1 3/4` now recognizes `1 3/4`
  as one and three fourths, instead of misreading it.
- **Task Type "Task".** Only notes created as tasks (from the Tasks view
  or Quick Task) show Type "Task" in the grid; a note that merely
  contains a checkbox task still shows Type "Note".
- **Quick Task prompts when no notebook is open.** A remembered notebook
  no longer silently receives a quick task; the app asks which library
  and notebook to use.
- **Find remembers your last search.** Reopening Find restores the
  previous search text and match list.
- **Citations in reading view.** Insert buttons are hidden in reading
  view, replaced by one "Switch to edit mode to insert citations"
  button that flips to edit mode and leaves the dialog open. Ctrl+J and
  Ctrl+Shift+C now work while the Citation dialog is open, and the
  generator and bibliography stay in sync: saving to the bibliography
  no longer drops other notebooks' entries, and the button reads "Add
  to Bibliography".

## Known limitations

- F3 and Shift+F3 remain intercepted by JAWS in browse mode; use the
  Find match list, or Insert+3 (JAWS pass-through) then F3, to repeat
  a search.
- Mac releases ship unsigned (right-click, then Open, to install; no
  Mac auto-update while unsigned).
- PDF, ePub, and DOCX previews keep their own search boxes; the Find
  match list does not cover them.
- Very large spreadsheets (thousands of rows) may be slow to display;
  the reader caps workbooks at 10,000 rows, 256 columns, and 500,000
  cells, and slide decks at 500 slides. Spreadsheet save preserves the
  file's styles, images, and other parts; ODS cells keep their original
  cell styles. `.xls` reading uses the SheetJS community edition
  (Apache-2.0) — the one format without an in-house reader.
- Items still awaiting a retest verdict: move-migration link survival,
  import formats, ePub chapter resume, PDF navigation and annotation
  persistence.

## Mac install note

Mac builds are not signed yet. To install, right-click (or Control-click) the .dmg file, then choose Open. In-app updates do not work on Mac while the builds are unsigned — install each new version manually from the releases page.
