# A11y Notebook v1.9.5 — What's new and what changed

Everything in this release was merged since v1.9.4 (October 29, 2026).
It fixes the second batch of verification findings from testing v1.9.4,
and adds the Provide Feedback option to the Help menu.

## What's new

- **Provide Feedback in the Help menu.** Send feedback about the app
  using the same form relay as FRAME PDF Studio: Message is required,
  Name and Email are optional, and only the message you type is sent.
  No notes, files, or library content are included.
- **Tutorial release-notes page.** The startup tutorial now ends with
  a "What's new in this version" page, so every update tells you what
  changed. The tutorial still opens automatically when the app updates,
  unless you checked "Don't show this again".

## What changed

- **Task reminder fields.** Reminder dates and times in task dialogs
  now use separate date and time fields instead of a combined
  date-time picker, matching the Create Reminder dialog, so dates and
  times can be typed without opening a picker. A reminder date without
  a time, or a time without a date, is refused with an error instead
  of silently dropping the reminder.
- **Shortcuts Manager imports.** The registry holds exactly two import
  commands: "Import file" brings a file from outside the library into
  a notebook, and "Import managed copy…" makes a managed copy of a
  file already in the library. With default settings the Shortcuts
  Manager lists only "Import file"; "Import managed copy…" appears
  only when a key is assigned to it.

## Fixes

- **Created notes keep their managed status.** Creating a note
  recorded the staging file's identity and assumed the linked target
  kept it. On filesystems where a link materializes as a new file,
  the record pointed at an identity that no longer existed, so
  closing and reopening the note showed the external-file dialog.
  Creation now records the target file's own identity.
- **New notes open ready to write, actually fixed.** The v1.9.4
  attempt did not hold: the mode effect overwrote the explicit edit
  mode with the default open mode when the new tab became current,
  and the creation dialog's focus restore stole the editor focus
  when it closed. A new note now opens in Editing mode with the
  editor focused, even when the default open mode is Reading, and
  notes created from a template open the same way, with the cursor
  placed by the template.

## Known limitations

- A note whose stored origin record already points at an identity
  that no longer exists (for example, a note created before this
  fix on an affected filesystem) still shows the external-file
  dialog once; choosing "Import into A11y Notebook" adopts it as a
  managed copy.
- Mac releases ship unsigned: install with right-click, then Open.
  Mac auto-update does not work while releases are unsigned.
