# A11y Notebook v1.9.6 — What's new and what changed

Everything in this release was merged since v1.9.5 (October 29, 2026).
It carries the single import command, the plain-text note format, and
the hide-originals work requested the same day.

## What's new

- **Original files are hidden once a managed copy exists.** When you
  import a managed copy from a file already in the library, the tree,
  the grid, Contents, Notebooks, and search results show the copy, not
  the original. Settings gains **Show original files** (off by
  default) to bring originals back. The original file is never modified
  or deleted, and deleting the managed copy brings it back on its own.
  Only imports made from this version on are recorded; earlier imports
  are not hidden retroactively.
- **Plain text joins the New note format list.** A new note can now be
  Markdown (.md), HTML (.html), or Plain text (.txt), with Markdown
  still the preselected default. A .txt note is created through the
  same note path and opens in the same editor.

## What changed

- **One import command.** "Import file" (Ctrl+Shift+I) is now the only
  import command. Without a selected library file it opens a file
  picker for a file from outside the library; on a selected library
  file it imports a managed copy of that file. The old "Import managed
  copy…" command is gone; a key saved for it is dropped harmlessly on
  settings load. In note menus, Import file sits right after Open
  selected item, as the old command did.

## Known limitations

- Mac releases ship unsigned: install with right-click, then Open.
  Mac auto-update does not work while releases are unsigned.
