# A11y Notebook v1.9.9 — What's new and what changed

Everything in this release was merged since v1.9.8 (October 29, 2026).
It carries Tristen's testing batch 5.

## What's new

- **Dialog window titles.** Every dialog now sets the window title
  while it is open and restores it on close, so the title bar and
  screen reader title announce which dialog is open. Pressing Enter
  on a dialog's text or heading now activates its default button.
- **Reminder sounds from any audio file.** Settings now offers a
  custom sound file choice alongside the gentle chime: pick any WAV,
  MP3, OGG, or M4A file on the computer, and the Test sound button
  previews the chosen sound.
- **Libraries picker on startup with no library.** When no library
  reopens at launch, the app now lands on the Libraries screen with
  focus on the grid, instead of an empty Notebooks view.
- **Library switch state restored.** Switching back to a library now
  restores its open notes, selected tab, and open Tasks, Reminders,
  and Calendar tabs, instead of landing on a bare Notebooks view.

## What changed

- **12-hour times accepted.** Reminder, appointment, and task dialogs
  now accept 12-hour times (2:30 PM) as well as 24-hour times
  (14:30). Values are still stored in 24-hour form. The reminder and
  appointment dialogs have Show Date Picker buttons again.
- **Shift+Delete deletes permanently, everywhere.** Shift+Delete in
  notes, files, notebooks, and libraries now deletes permanently with
  permanent wording; plain Delete still sends items to the Recycle
  Bin. Library delete failures now report the real error instead of
  a generic failure message.
- **Import file into its own folder hides the original.** Picking a
  file already inside the library and importing it into the folder
  it already lives in now creates a uniquely named copy and hides
  the original, matching managed copies. Imports into any other
  folder are unchanged: the exact filename is kept, and re-importing
  still rejects as a duplicate.
- **Alt+Left no longer double-presses.** Retargeting the tree while
  a note is open no longer records an invisible history step, so one
  Alt+Left returns to the previous location.
- **List continuation is announced.** Continuing a Markdown list
  now announces the next marker ("3.", "bullet", "task") or "List
  ended." Insert Link now focuses the Link text field first, and the
  wiki Note picker lists every note, including notes imported before
  origin tracking.
- **Grid stays visible beside an open note.** The Notes and Files
  grid remains displayed and usable while a note or file is open;
  the only exception is Focus Mode, which hides the navigation pane.
  Ctrl+Tab and Ctrl+Shift+Tab now announce the tab they land on.
- **Find repeat moves focus in reading mode.** F3 and Shift+F3 after
  the Find dialog closes now move keyboard focus into the document
  at the match, matching edit mode.
- **Bibliography shortcut restored.** Ctrl+Shift+J now opens the
  bibliography (and Ctrl+Shift+C the citation generator): the main
  process forwards them on Windows and Linux, since Chromium
  otherwise reserves them for DevTools.
- **Math template starts empty.** Alt+= now inserts an empty math
  template with the caret inside it, instead of a prefilled
  square-root expression.
- **Focus Mode shows only the document.** Focus Mode now hides the
  note-action buttons (Convert, Export, Save, bookmarks, formatting
  toolbar) and the Plain source / Rich text toggle, leaving only the
  title, menu, search, and document. The Focus Mode on/off
  announcement is now heard every time.

## Known limitations

- Mac releases ship unsigned: install with right-click, then Open.
  Mac auto-update does not work while releases are unsigned.
