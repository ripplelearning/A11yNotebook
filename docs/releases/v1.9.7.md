# A11y Notebook v1.9.7 — What's new and what changed

Everything in this release was merged since v1.9.6 (October 29, 2026).
It carries Tristen's testing batch 3.

## What's new

- **Ctrl+W closes tabs, notebooks, and libraries.** The Close current
  tab command is now Close current item: on a tab it closes the tab,
  on a selected notebook it clears the selection, and on a library it
  closes the library. Closing a library closes every open note, file,
  task, reminder, asset, and attachment tab plus the notebook
  selection, returns to the Libraries view, and focuses the libraries
  grid. Unsaved changes still block closing a library, exactly like
  they block opening another one.
- **Libraries can be deleted.** Focus a library in the Libraries grid
  and press **Delete**, or choose **Delete library** from its context
  menu. The confirmation warns that everything inside the library goes
  too, including notebooks, notes, files, tasks, and reminders, with
  Delete as the first button, Cancel, and Escape cancelling.
  Confirming moves the whole library folder to the Recycle Bin. Only a
  recently opened library or the open one can be deleted this way.
  Deleting the open library closes it first; unsaved changes block the
  delete.
- **Opening a library lands on the Notebooks view**, not Notes and
  Files.

## What changed

- **Search box first, scope right after it.** The search box is now
  the first element in the header, and the search scope radios sit
  right after it, so scope can be chosen without navigating away from
  the box. The results section keeps its heading, filters, and scope
  announcements; only the radios moved.

## Known limitations

- Mac releases ship unsigned: install with right-click, then Open.
  Mac auto-update does not work while releases are unsigned.
