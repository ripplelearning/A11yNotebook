# A11y Notebook v1.9.10 — What's new and what changed

Everything in this release was merged since v1.9.9 (October 30, 2026).
It carries testing batch 6, the Organize Library dialog, the reopen
landing, the closed-app reminder change, Interaction settings, and
user guide updates.

## What's new

- **Organize Library dialog.** The library tree now lives in an
  Organize Library dialog opened from the View menu
  (Ctrl+Shift+V), with the tree as its primary content. Edits
  inside the dialog are staged: OK applies them all, Cancel
  discards them, and Escape closes and returns focus. The dialog
  offers rename (F2), move (Alt+Up/Down into the previous or next
  notebook, Alt+Shift+Up/Down out one level, or the Move dialog
  for any other destination), open (Enter), delete
  (Delete/Shift+Delete), cut/copy/paste, protect, properties, and
  send to email. Protect blocks editing, moving, deleting, and
  renaming a protected item; attempting one opens a dialog stating
  the item is protected, with Unprotect (which removes protection
  and immediately carries out the action) and Cancel. Email
  generates a .eml file with the file attached and opens it in the
  default mail app. Items at the library root are reachable through
  the dialog tree and global search only; there is no persistent
  tree pane in the main view anymore.
- **Reopen restores the last notebook.** Reopening a library now
  restores the last notebook that was open, showing its Notes and
  Files view, instead of landing on the Notebooks view. If nothing
  was recorded, or the notebook is gone, it falls back to the
  Notebooks landing as before.
- **Closed-app reminders open the window on the due reminder.**
  A reminder that comes due while the app is closed and the
  machine is awake now shows its notification AND opens the app
  window focused on the due reminder (the earliest-due one wins
  when several are due). A sleeping machine is still never woken;
  a missed fire still comes late on the next wake.
- **Interaction settings.** Two new settings, both off by default:
  Immersive Focus mode, which also hides the search box and search
  scope while Focus mode is on, and auto-focus on grids when
  switching views, which puts keyboard focus in the grid when
  switching to the Libraries, Notebooks, or Notes and Files view.
- **Reading view task checkboxes.** Reading view now renders task
  list items as real disabled checkboxes, including empty, nested,
  and ordered items. Toggling stays in edit mode and Tasks view.
- **In-dialog reminder calendar and AM/PM times.** Reminder dates
  are now picked from a calendar inside the dialog (one tab stop,
  arrow-key day navigation) instead of the browser's native date
  popup, and reminder times use an AM/PM choice alongside the
  12-hour field. Appointments use the same calendar.
- **Thesaurus synonyms are buttons, with online definitions.**
  Each synonym is now a button, and per-synonym Lookup buttons
  fetch definitions from a free online dictionary. Nothing is sent
  unless Lookup is pressed.

## What changed

- **Ctrl+Tab cycles open tabs only.** Ctrl+Tab and Ctrl+Shift+Tab
  now cycle the selected notebook's Notes and Files stop, open
  Tasks, Reminders, Calendar, and cognitive-tool tabs,
  attachments, and open notes in tab-strip order. Generic
  Libraries, Notebooks, and Notes and Files screens, settings,
  and dialogs are never stops. Each open note keeps its mode and
  caret when switching tabs; a note that locks while open forces
  read-only, and unlocking returns to the default mode.
- **Find close lands focus at the match.** Closing the Find dialog
  now leaves focus in the document at the match in both reading
  and edit mode, so the surrounding context can be read at once.
- **Import and link pickers widened.** The Import picker lists
  Google Docs link (.gdoc) files, with the existing guidance
  message on pick instead of a generic error. The appointment link
  picker now offers every non-asset note, including notes whose
  origin record was lost.
- **Bibliography hanging indent.** Bibliography entries inserted
  into HTML notes now use a 0.5 inch hanging indent, with book,
  container, and journal titles italicized and article titles
  quoted. Markdown cannot express a hanging indent, so Markdown
  inserts are unchanged.
- **Task files named after their task.** Task files created from
  Tasks view are now named after their task text instead of a
  generated identifier, and task files stay in Notes and Files
  where they can be edited, deleted, or extended.
- **Batch 6 chunk 1 fixes.** The Move Item and Repair Links button
  is now first and default in its dialog; Ctrl+N in calendar view
  opens a new appointment; DetailsView Home and End jump to the
  first and last row; citation lookup errors no longer name
  internal methods; the bibliography opens in reading view; and
  bookmark command descriptions are clarified.
- **User guide updated.** The guide now documents the Organize
  Library dialog, the reopen landing, closed-app reminders, and
  the Interaction settings, and no longer describes the old
  main-view tree or the old "nothing fires after exit" reminder
  behavior.

## Still open

Two testing items remain open and do not block this release: the
Settings dialog title and the Focus Mode buttons items still need
exact steps to reproduce, and the F3 key itself still awaits
retest on a shipped release.


## Mac install note

Mac builds are not signed yet. To install, right-click (or Control-click) the .dmg file, then choose Open. In-app updates do not work on Mac while the builds are unsigned — install each new version manually from the releases page.
