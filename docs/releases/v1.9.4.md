# A11y Notebook v1.9.4 — What's new and what changed

Everything in this release was merged since v1.9.3 (October 28, 2026).
It fixes the first batch of verification findings from testing v1.9.3.

## What's new

- **Reminders on Ctrl+7.** The Reminders view now opens with Ctrl+7, a
  Ctrl+number combination; the old Ctrl+Shift+R still works as an alias.
  Ctrl+N creates a reminder while the Reminders view is open.
- **Shift+Delete permanently deletes.** Shift+Delete on a selected note
  or file permanently deletes it (it does not go to the Recycle Bin),
  with its own confirmation dialog. Inside a text field, Shift+Delete
  still cuts text as usual.
- **New notes open ready to write.** A note you just created opens in
  Editing mode with the editor focused, regardless of the default open
  mode.

## What changed

- **Tutorial dialog.** Moving between tutorial pages is now announced
  to screen readers, the bottom controls run Next/Finish, Previous,
  "Don't show this again", Close, and the window title shows the
  tutorial while it is open.
- **Window titlebar.** Every screen's titlebar now ends with
  "A11y Notebook". The in-page "A11y Notebook" heading is removed, so
  there is one less element to navigate through on every screen.
- **Settings.** The scoped metadata encryption explainer is collapsed
  by default, so saving settings no longer reads the whole explainer
  aloud.
- **Reminders.** The Create Reminder button is available whenever the
  Reminders view is shown, and it stays available after switching
  views; a fired reminder now brings the app window forward so its
  dialog appears at the due time instead of only when the app is
  reopened. One unreadable note no longer fails the whole reminder
  update, and a broken standalone reminder is reported once instead of
  on every refresh.
- **Import commands.** "Import internal copy" is merged into
  "Import managed copy…": they ran the same operation, so there is now
  one command for it, available from the tree, attachments, document
  previews, and search results. "Import file…" (the file picker for
  files outside the library) is unchanged and separate. A shortcut you
  had assigned to the removed command is dropped by settings
  validation; reassign it to "Import managed copy…" if you need it.
- **Reveal in Explorer.** "Reveal this item in Explorer" now works
  from a shortcut assignment and from a note tab, not just from the
  tree context menu; assigning it previously reported
  "Command not recognized."
- **Undo.** Ctrl+Z and Ctrl+Y outside the note editor now route to the
  unified undo timeline, so toggling a task checkbox and pressing
  Ctrl+Z returns the task to the list. Text fields keep their native
  undo, and open dialogs keep their own keyboard behavior.
- **Delete confirmation.** The delete confirmation now puts Delete
  first as the default button, and Escape cancels.

## Fixes

- Fixed the Create Reminder button staying disabled after the first
  reminder, across view switches and restarts, for notes whose
  provenance the app did not record.
- Fixed a fired reminder playing its sound with no dialog while the
  app window was unfocused.
- Fixed "Could not update reminders." repeating on restart when one
  note could not be read or one standalone reminder was broken.

## Known limitations

- A reminder that fires while the app is closed still delivers only
  the operating-system notification, by design; it does not open the
  app window. Whether the closed-app case should also open the window
  is an open question for a future release.
- The "Open external file" dialog for testing.md is unchanged: a file
  created outside the app is not an app note until imported, and
  importing creates a separate managed copy while leaving the original
  untouched.
