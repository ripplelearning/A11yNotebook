# A11y Notebook v1.9.0 — What's new and what changed

Everything in this release was merged since v1.8.0 (October 26, 2026).
This is the first release to ship Windows and Mac together.

## What's new

- **macOS support (unsigned first).** A11y Notebook now ships for Mac as
  a dmg and a zip, for Apple Silicon and Intel, alongside the Windows
  installer and portable builds. On Mac, Command acts as Ctrl for every
  command, and a physical Ctrl press never triggers one, so VoiceOver's
  Ctrl+Option modifier cannot fire app commands by accident. Shortcut
  capture accepts Command, the app uses the standard macOS application
  menu, Explorer is named Finder, and the OS Reduce Motion and Increase
  Contrast settings are honored. Install via right-click → Open until
  signing is set up; in-app updates do not run on Mac while unsigned.
- **Heading and position bookmarks.** Bookmark a heading or the exact
  position at the edit caret (Ctrl+Alt+H to set, Ctrl+Alt+J to jump),
  alongside the existing note bookmarks.
- **General YAML metadata editing.** Edit any front-matter field, not
  just the built-in ones, with suggestions drawn from values already in
  the library. Fields you don't touch round-trip verbatim.
- **Note reading positions.** Notes remember where you were reading:
  heading anchors alongside the existing ePub positions, a debounced
  save, and a "Resumed at <heading>" announcement when you return.
- **Missing-link repair prompts.** When a note links to a target that
  doesn't exist, a repair dialog offers, per link, to create the note or
  retarget the link; the Info pane also offers Repair for the current
  note.
- **Unified undo timeline.** Undo and redo now follow one chronological
  timeline across per-note edits and task toggles: edit, toggle a task,
  then undo, and the toggle is what undoes. Toggles are redoable, and
  closing a note clears its timeline entries.
- **Opt-in task names in wake alerts.** A new setting, "Name reminders
  in alerts after the app closes" (off by default), lets reminders that
  fire while the app is closed name the task instead of announcing only
  that a reminder is due. Turning the setting off takes effect at once;
  flashcard reviews and locked-library alerts stay generic either way.
- **Apple calendar picker.** Apple Calendar sync now lets you pick a
  calendar per library instead of always using the first calendar.

## What changed

- **Links now follow moves.** Moving a note or notebook rewrites its
  task links and calendar links (and the task ids inside the moved
  note) instead of orphaning them. The same migration runs for live
  moves and for crash recovery, so an interrupted move ends in the same
  state. Appointment ids are untouched, so nothing echoes to a provider.
- **Task-link hygiene.** Links created by outside edits are now tracked
  the same as links created in the app, and deleting a note or notebook
  drops its task links; saving a note drops links to tasks the save
  removed.
- **Exited-process reminders, decided.** The scheduled task never wakes
  a sleeping machine: if the machine is awake it fires, otherwise the
  reminder fires late on the next wake. This was already the behavior;
  it is now the recorded decision.
- **Mind-map layout.** Radial maps grow their radius until nodes no
  longer overlap, and connectors attach at box edges instead of centers.
- **End-to-end coverage.** The seeded-library end-to-end suite now runs
  the full library flow, and crash-atomic move recovery covers
  reminders.

## Fixes in this release

- Reference-style Markdown link repair now handles CRLF line endings.
- Mind-map nodes no longer overlap on radial layouts.
- Task links no longer go stale when a note is edited outside the app.
- Orphaned task links no longer linger after a note or notebook is
  deleted.

## Known limitations

- **Unsigned builds.** Windows may show SmartScreen warnings and macOS
  may show Gatekeeper warnings (install via right-click → Open). There
  is no code-signing certificate yet, and no Apple Developer account for
  Mac signing and notarization.
- **Mac icon.** The Mac icon was generated from the Windows icon's
  256px image (the largest source available), so large icons render
  soft until a higher-resolution source exists.
- **Mac in-app updates do not run while unsigned.** Mac users download
  new versions from the release page.
- **Background reminders are Windows-only.** The setting is labeled as
  such on Mac; exited-process alerts do not fire on macOS.
- **Calendar sync is not yet tested against real accounts.** Google,
  Outlook, and Apple sync are built and unit-tested, but live-provider
  testing still needs real accounts.
- **First sync can duplicate events** that already exist both locally
  and remotely without a link. Links and reminder choices are local-only
  and do not transfer through a provider to a fresh library.
- **Exited-process registration failures are silent.** There is not yet
  a failure-status display in Settings.
- **macOS file-watcher quirks.** On macOS, the system file watcher
  sometimes delivers a change event without a filename, and it reports
  activity inside a symlinked folder on the parent watch as activity on
  the link itself. The library scan itself still refuses to follow
  symlinked folders; these are reporting quirks, not followed links.
- **Manual validation still owed:** on Windows, JAWS/NVDA/Narrator runs,
  forced-colors rendering, UI Automation smoke runs, Task Scheduler
  reminder delivery, the paste clipboard path, and the reported File
  Explorer invisibility; on Mac, VoiceOver and Zoom validation, the dmg
  install and Gatekeeper flow, and real shortcut behavior.
